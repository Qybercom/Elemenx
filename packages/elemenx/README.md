# elemenx

`elemenx` is the short name of [`@qybercom/elemenx`](https://www.npmjs.com/package/@qybercom/elemenx), the Elemenx browser UI framework: it depends on the same version of it and runs its CLI.

```bash
npm install elemenx
npx elemenx help
```

Both names install the same framework, its CLI and the ElemenxUI library; the documentation, the distribution (`dist/`) and the CDN links are those of `@qybercom/elemenx`.
