CloudBlueprints: облака точек из графов Blueprints, объявленные в $Provides (Blueprints создаёт службу, когда встречает такой граф или блок). Граф вида cloud заканчивается блоком Cloud и запускается по разу на каждую точку: его блоки Input читают Index (номер точки, 0 — первая), Count и то, что ему передано (чаще всего Seed), а Cloud принимает, какова точка: Position (vec3), Color (vec4: r, g, b и яркость), Size, Keep (false — точка отбрасывается) и по числу на каждое поле из Fields (имена: 'Distance, Spin'). Count (вход, иначе свойство, до миллиона) читается один раз, у точки 0; Least (расстояние) отбрасывает точку, лежащую ближе него к уже принятой, так что точки ложатся врозь, как диск Пуассона. Числа берутся из зерна Astronomy.Random блоком Draw (Seed, Index · сколько чисел берёт точка + номер числа): граф выбирает те же числа, что код, бравший их одно за другим.
- Points(graph, parameters, inputs) — запускает граф (объект, его JSON или имя ресурса): {Count (принятых точек), Positions (Float32Array, тройками), Colors (четвёрками), Sizes, Fields ({имя: Float64Array})}; Positions, Colors и Sizes есть, когда граф их задаёт. Строится один раз для того же графа, параметров и входов (хранятся последние 32). Код делается из графа (Blueprints.Code: без обхода блоков на каждую точку), иначе граф идёт как есть.
- Его блоки стоят в любом графе чисел (generator и видах, которые его используют):
  Sphere (U, V от 0 до 1 — точка на шаре радиуса Radius, поровну на каждый его участок; Z из U от -1 до 1, поворот из V), Shell (то же внутри шара от Inner до Outer, поровну в каждом объёме; W — глубина), Disc (U, V — точка на плоском кольце от Inner до Outer, в X и Z), Spiral (U, V, Arm — целое: на одном из Arms рукавов логарифмической спирали с шагом Pitch градусов от Inner до Outer, шириной Spread), Gauss (U, V — число нормального распределения, Middle и Deviation), Plummer (U, Scale — как далеко звезда скопления профиля Пламмера от его середины), Fibonacci (Index, Count — точки спирали Фибоначчи, как можно ровнее по шару радиуса Radius), Pick (Value от 0 до 1 — один из List, иначе из Items, как берёт Random.Pick) и Blackbody (Temperature в кельвинах — цвет звезды такой температуры, 0–1, как его даёт Astronomy.Color).
Облака библиотеки (ElemenxGraphics/cloud/<имя>): sky (звёзды космоса вокруг глаза), night (ночи на земле), cluster (рой звёздного скопления: Seed, Scale), belt (камни пояса: Seed, Count, Inner, Outer, Tilt, Radius, Unit, Factor, Body, Rocks, Colors; поля Distance, Eccentricity, Inclination, Node, Periapsis, Anomaly, AxisX, AxisY, AxisZ, Spin). Те же функции работают в Node: страницу они не читают.
