NetworkBlueprints: сети из графов Blueprints, объявленные в $Provides (Blueprints создаёт службу, когда встречает такой граф или блок): реки, дороги, рельсы, трассы. Граф вида network заканчивается блоком Network и даёт сеть: {Nodes: [{ID, At, Kind, Rank}], Ways: [{ID, From, To, Points ([x, z] на земле, [x, y, z] — направления на глобусе), Class, Closed, Values ({имя: число или по числу на каждую точку})}]}. Его блоки — шаги: каждый — алгоритм кода, заданный свойствами и входами, сеть на входе и сеть на выходе; блоки чисел генератора тоже доступны — для их чисел. Граф превращается в код (Blueprints.Code, каждый блок — вызов этой службы), поэтому работает и в странице, и в воркере, который несёт эту службу и те, что вызывают её блоки (ScenePlanet, SceneTerrainGenerator, SceneRoads).
- Make(graph, parameters, inputs) — запускает граф (объект, его JSON или имя ресурса) и отдаёт его сеть.
- Sample(graph) — с чем граф запускается, чтобы его увидеть (BlueprintPreview): {имя: значение} его блоков Input — Heights и Size небольшой планеты, Field — земля, Hubs — несколько городов, Passages и Trunks — пустые.
- Code(graph) — его код ({Source, Run, Keys}: Run(parameters, inputs) даёт {Network}); из Source воркер делает Run (new Function('B', 'M', 'N', Source)(Blueprints, Math, Noise)).
- Блоки (и функции службы с теми же именами): Ways (List — линии или {Points, Class, ID, Values}, Class, Closed: сеть из них), Merge (A, B: одна за другой), Ring (Seed, Corners (0 — от 9 до 14 по зерну), Wild, Length, Squash: замкнутый путь вокруг середины, его точки ближе и дальше, без самопересечений; Of random — числа Random.Create; Values Draws — сколько чисел взято), Fit (Length, Step: каждый замкнутый путь нужной длины, Places знаков после точки; Values Fit — во сколько раз растянут), Connect (Hubs [{X, Z, Rank}], Passages ([x, z]: пути извне), Trunks (сеть магистралей), Big (ранг города, 2), Gap (метры, на которых магистраль считается рядом, 30): города и посёлки соединяются кратчайшей сетью (Прим), крупные первыми, с магистралью, если она ближе всех соединённых; каждое меньшее — к ближайшему уже соединённому; проходы — каждый к ближайшему поселению), Route (Field: каждый ещё не проложенный путь ведётся по земле A* из SceneTerrainGenerator.RoadWay, MaxGrade, Bridge; Keep — путь, который не прокладывается, остаётся прямым, иначе выпадает), Classify (Main, Minor, Paths: класс каждого пути по рангу — у магистрали свой, Main между городами и посёлками, Minor к одному из них, Paths остальные), Beside (Offset метров вправо, Rank, Class, On: копия каждого пути этого ранга и выше рядом с ним, Places знаков после точки), Smooth (Rounds проходов Чайкина: углы срезаются, значения идут вдоль; Sphere — точки остаются на единичном шаре), Round (Places знаков у точек, Digits — у значений) и Drainage (Heights, Size, Least: реки планеты по высотам её клеток — ScenePlanet.DrainageWays, их Flow и Level вдоль них).
Сети библиотеки (ElemenxGraphics/network/<имя>): rivers (планеты: ScenePlanet.Drainage), roads (мира: шаг Roads в SceneWorld), track (гоночная трасса: SceneRoadGenerator.Track). Те же функции работают в Node.
