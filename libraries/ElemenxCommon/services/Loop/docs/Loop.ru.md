Цикл игры или любого мира. Create({Step, Update, Render, Speed, MaxSteps, Window}): Update(step, loop) — на каждый Step игрового времени (1000 / 60 мс) при любой частоте экрана, Render(alpha, loop) — раз в кадр (alpha — доля шага после последнего обновления, чтобы рисовать между состояниями). Start(), Stop(), Pause(), Resume(), Advance(elapsed) (время вручную: тест), Running, Paused, Time, Ticks, Fps, Now (время кадра на экране, null до первого, даже если его очередь пришла с опозданием), Speed, MaxSteps (5: вкладка, вернувшаяся из фона, не прогоняет потерянные минуты). Window даёт кадры (по умолчанию окно страницы); где его нет (Node, воркер), цикл идёт на таймерах, кадр раз в 16 мс.
