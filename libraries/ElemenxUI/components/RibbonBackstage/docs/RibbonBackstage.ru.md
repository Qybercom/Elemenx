Представление «Файл» ленты Ribbon, как в Microsoft Office: <RibbonBackstage slot="backstage"> с дочерними RibbonPage. Кнопка «Файл» ленты открывает его поверх её Workspace (без неё — поверх окна): список страниц сбоку, содержимое текущей рядом. Кнопка «назад» и Escape закрывают его. Page — текущая страница. События: page ({ID}). Команды среди страниц сообщает лента (command).
