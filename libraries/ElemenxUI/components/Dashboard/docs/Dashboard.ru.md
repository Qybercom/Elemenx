Раскладка панели управления на основе elemenx-screen, elemenx-container и elemenx-column. Слоты: nav (боковая панель, часто NavList), header, по умолчанию (содержимое: адаптивная сетка DashboardWidget; любой элемент с классом elemenx-dashboard-wide занимает всю строку), footer. Область показывается, только пока её слот что-то рисует; боковая панель сама сужается вокруг свёрнутого NavList.
