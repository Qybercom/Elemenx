# DesignerPalette

Палитра конструктора страниц (сервис Designer): виды, которые он умеет ставить, по группам, с поиском. Нажатый вид попадает в выбранный элемент, если это контейнер, иначе — после него, а без выбора — в конец страницы, и становится выбранным; перетащенный вид (*draggable, тип elemenx-designer-kind) попадает туда, где его принимает DesignerCanvas. Подсказка вида — описание, которое компонент объявляет в $Meta. События: add (ID нового элемента).

## События

- `add`: Вид элемента поставлен на страницу: ID нового элемента.
