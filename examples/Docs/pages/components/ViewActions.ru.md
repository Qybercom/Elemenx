# ViewActions

Действия вида редактора — панель над низом вида, одна и та же для мыши и пальцев. Items [{ID, Icon, Label, Disabled, Danger}] — кнопки, нажатие сообщает act ({ID}). Hand (true или false; null — без него) — переключатель, отдающий камере один палец (два пальца двигают её всегда), сообщается событием hand ({Hand}). Label называет панель для экранных дикторов. Есть у SceneEditor, ModelEditor и PlanetEditor; их контекстное меню (правая кнопка, долгое нажатие пальцем) показывает те же действия.
