# Сеть

`Elemenx.Network` даёт одну модель всем способам, которыми страница говорит с сервером или с другой страницей: запрос, поток ответа, длинный опрос, события сервера (SSE), WebSocket, канал данных WebRTC, большая передача по частям и измерение трафика любого из них. Каждый — ресурс одинакового вида: его настраивают, запускают, он сообщает о происходящем событиями, его закрывают или уничтожают. Ни один не возвращает Promise.

| Ресурс | Что это | Запуск | Остановка |
| --- | --- | --- | --- |
| [XHR](/network/xhr) | один запрос и его ответ | `Execute()` | `Abort()` |
| [Stream](/network/stream) | ответ, читаемый по частям по мере прихода (`fetch`) | `Connect()` | `Close()` |
| [LongPolling](/network/longpolling) | запрос, который сервер держит, пока не появятся новости, — снова и снова | `Connect()` | `Close()` |
| [SSE](/network/sse) | события сервера (`EventSource`) | `Connect()` | `Close()` |
| [WebSocket](/network/websocket) | двусторонний сокет с обратным давлением | `Connect()` | `Close()` |
| [WebRTC](/network/webrtc) | канал данных между двумя браузерами, с обратным давлением | `Connect()`, `CreateOffer()` | `Close()` |
| [Transfer](/network/transfer) | большое значение (файлы, объект с файлами), отправляемое или принимаемое частями с прогрессом | `Send()`, `Execute()` | `Abort()` |
| `TransferReceiver` | принимающая сторона передачи по частям | (слушает) | `Destroy()` |
| [Metrics](/network/metrics) | байты и скорости ресурса | `Start()`, `Begin()` | `End()`, `Stop()` |

Ещё две части дополняют их: [протокол](/network/protocols) превращает то, что ресурс отправляет и получает, в типизированные сообщения, а [контекст](/network/contexts) даёт нескольким ресурсам один протокол, общих слушателей и настройки.

## Создание ресурса

Ресурс создаёт фабрика `Elemenx.Network` — с настройками в объекте или сеттерами один за другим:

```js
var request = Elemenx.Network.XHR({Method: 'GET', URL: '/api/hello', ResponseType: 'json'});

var same = Elemenx.Network.XHR()
	.Method('GET')
	.URL('/api/hello')
	.Header('Accept', 'application/json');
```

Сеттеры возвращают ресурс, поэтому их можно сцеплять; сеттер, вызванный во время работы ресурса (выполняющийся запрос, открытый сокет), игнорируется.

## Ресурсы владельца

Внутри компонента, сервиса или приложения используйте `this.$Network()` вместо `Elemenx.Network`. Созданные так ресурсы принадлежат владельцу: когда компонент уничтожается, его запросы прерываются, сокеты закрываются, передачи уничтожаются — ничто не продолжает работать для ушедшей страницы. Ресурс, созданный после уничтожения владельца, выбрасывает `Elemenx Network owner is destroyed`.

```js
Elemenx.Component('Weather', {
	$Template: '<p>{{Text}}</p>',
	Text: 'Loading...',

	$OnReady: function () {
		var self = this;

		this.$Network().XHR({URL: '/api/weather', ResponseType: 'json'})
			.On('Transport.Success', function (event) {
				self.Text = event.Data.Response.Summary;
			})
			.Execute();
	}
});
```

`this.$Network('Name')` даёт фасад, каждый ресурс которого получает контекст `Name` (см. [Контексты](/network/contexts)). Приложение объявляет контекст через `this.$Network('Name', definition)`.

## События

Каждый ресурс сообщает о событиях через `On(name, callback)` и `Off(name, callback)` (`Off(name)` снимает всех слушателей этого имени). У события есть пространство имён и тип, и слушатель выбирает, сколько слышать:

- `On('Transport', callback)` — все события транспорта (`BeforeRequest`, `Open`, `Data`, `Close`...);
- `On('Transport.Success', callback)` — один их тип;
- `On('Protocol.JSON', callback)` — сообщение, декодированное [протоколом](/network/protocols) ресурса;
- `On('Transfer.Progress', callback)` и `On('Metrics.Update', callback)` — события Transfer и Metrics.

Обработчик получает `(event, context)`. Событие — `{Namespace, Type, Data, Target}`: в `Data` — то, о чём событие (ответ, полученные данные, код закрытия...), в `Target` — ресурс. Событие протокола получает в `context` событие транспорта, которое его принесло.

Исключение в слушателе сообщается как необработанная ошибка, как DOM делает для своих слушателей; остальные слушатели всё равно вызываются.

## Время

Каждый ресурс хранит моменты своей жизни: `$StartedAt()` (когда создан), `$ConnectedAt()` (когда открылся или запрос начался) и `$ClosedAt()` (когда закрылся или закончился); ещё не наступивший момент — `null`.

## Что выбрать

- Один запрос с ответом — [XHR](/network/xhr). Прогресс выгрузки и загрузки — события.
- Длинный ответ, который нужно показывать по мере прихода (журнал, строки JSON, генерируемый текст), — [Stream](/network/stream).
- Новости от сервера в одну сторону — [SSE](/network/sse), где сервер может держать ответ открытым, и [LongPolling](/network/longpolling), где не может (старый прокси, serverless-функция).
- Сообщения в обе стороны — [WebSocket](/network/websocket).
- Между двумя браузерами, без сервера посередине, — [WebRTC](/network/webrtc).
- Файлы и большие значения с прогрессом, паузой и повторами — [Transfer](/network/transfer) поверх любого из них.

Примеры этого раздела работают с сервером справки: `/api/hello`, `/api/echo`, `/api/events`, `/api/poll`, `/api/stream` и сокет `/api/socket`.
