# Директивы

Директива — атрибут, начинающийся с `*`. Структурная директива решает, строить ли её элемент и сколько раз; поведенческая добавляет поведение уже существующему элементу. В Elemenx есть структурные; ElemenxUI и приложения добавляют поведенческие.

## Встроенные

| Директива | Что делает |
| --- | --- |
| `*if="Condition"` | строит элемент, пока условие выполняется, и уничтожает, когда нет |
| `*for="item of List"` | строит его для каждого элемента; `item in Object` — для ключей, `i = 0; i < 5; i++` — цикл со счётчиком; `$index` — место |
| `*key="item.ID"` | даёт имя каждому элементу `*for`, чтобы элемент DOM и компоненты перемещались вместе с ним |
| `*keep` | компонент, скрытый `*if`, засыпает, а не уходит, когда кэш сохраняет экземпляры (см. [Ленивая отрисовка и кэш](/guide/cache)) |
| `*lazy="Placeholder"` | строит элемент вблизи экрана или когда браузер простаивает |
| `*outlet="Content"` | куда маршрутизатор ставит страницу маршрута (см. [Маршрутизатор](/guide/router)) |
| `*pending="#id"`, `*error="#id"` | что показывает компонент, который ещё загружается или не смог загрузиться (см. [Жизненный цикл](/guide/lifecycle)) |

У элемента не больше одной структурной директивы (`*if`, `*for`, `*lazy`); `*key` и `*keep` — аргументы той, что есть. Для условия вокруг списка вкладывайте два элемента. Поведенческих директив на одном элементе может быть сколько угодно.

| Хук | Когда |
| --- | --- |
| `$OnCreate(context)` | элемент в шаблоне, до первого значения |
| `$OnUpdate(context)` | значение выражения вычислено: в первый раз и при каждом изменении прочитанного |
| `$OnDestroy(context)` | элемент уходит |
| `$OnSleep(context)`, `$OnWake(context)` | компонент вокруг засыпает и просыпается |

Контекст — `{Name, Element, Component, Expression, Value, Data}`: элемент, компонент шаблона (он же `this` в хуках), текст выражения, его текущее значение и `Data` — собственный объект директивы для этого элемента. У директивы без значения (`*autofocus`) `Value` равно `undefined`.

Имя директивы пишется строчными латинскими буквами, цифрами, `-` и `_` и начинается с буквы; регистр при сравнении не важен (`*Tooltip` — это `*tooltip`). Повторная регистрация имени выбрасывает `Elemenx directive already registered: <name>`.

## Структурная директива

@block 5

Структурная директива владеет своим элементом: элемент становится шаблоном, который директива строит и убирает. В её контексте есть `Mount()` (строит, один раз), `Unmount()` (убирает; с `*keep` и кэшем, который его сохраняет, — усыпляет), `Mounted()` и `Marker` — узел, отмечающий место.

Директива коллекции (`Structural: true, Collection: true`) строит элемент для многих элементов данных: в её контексте есть `Source(expression)` (значение выражения в области видимости шаблона), `Argument(name)` (аргумент вроде `*key`) и `Render(items, {Mode, Variable, Key})`, как у `*for`. Директива-аргумент (`Kind: 'argument', For: 'collection'` или `'structural'`) — настройка, которую они читают.

## Правила

- У элемента не больше одной структурной директивы; для двух вкладывайте элементы.
- Аргумент допустим только рядом со структурной директивой того хоста, для которого он сделан (`For`).
- Поведенческие директивы создаются в порядке атрибутов, обновляются в том же порядке и уничтожаются в обратном.
- Поведенческая директива под структурной живёт вместе с поддеревом, которое та строит: создаётся, когда оно построено, и уничтожается, когда оно уходит.
