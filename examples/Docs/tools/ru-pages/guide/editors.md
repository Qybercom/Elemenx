# Редакторы и IDE

У Elemenx есть расширения для VS Code, IDE от JetBrains (WebStorm, IntelliJ IDEA, PhpStorm...) и Visual Studio 2022, а также языковой сервер для остальных редакторов. Они знают компоненты, свойства, события, директивы и сервисы вашего проекта и ElemenxUI.

## Установка

| Редактор | Где |
| --- | --- |
| VS Code, VSCodium, Cursor, Windsurf | магазин расширений редактора (VS Code Marketplace или Open VSX): **Elemenx** |
| WebStorm, IntelliJ IDEA, PhpStorm... | Settings → Plugins → Marketplace: **Elemenx**; он установит нужный ему LSP4IJ |
| Visual Studio 2022 (17.10 и новее) | Extensions → Manage Extensions: **Elemenx** |
| Neovim, Zed, Sublime Text, Helix... | языковой сервер из репозитория: `node editors/server/elemenx-language-server.js --stdio` |

Каждый релиз Elemenx также прикладывает файлы расширений к своему релизу на GitHub (`elemenx-vscode.vsix`, `elemenx-intellij.zip`, `elemenx-visualstudio.vsix`) для установки с диска. Версия расширений совпадает с версией Elemenx. Плагину JetBrains, расширению Visual Studio и языковому серверу нужен Node.js; `ELEMENX_NODE` указывает другой Node, не тот, что в `PATH`.

## Что они умеют

- **Автодополнение**: компоненты и их свойства, привязки (`[Variant]`), события (`(click)`) и варианты значения свойства (`Variant="ghost"`); директивы (`*if`, `*for`, `*tip`...); поля и функции компонента в выражениях его шаблона; сервисы в `$Service('...')`; ссылки в `$Ref('...')` и `$Refs('...')`.
- **Подсказки при наведении**: документация компонента, свойства, директивы, сервиса, поля или ссылки.
- **Переход к определению** (Ctrl+клик): компонент, сервис, поле или функция шаблона, директива (и встроенные тоже), свойство (его ключ в определении), событие (`$Emit`, который его отправляет), ссылка (`#Name` и `$Ref('Name')` ведут друг к другу), `$T` (его определение в `elemenx.js`) и ключ `$T('ui.call.leave')` (его фраза в ближайших `locales/*.json`, английская первой; при наведении видна фраза на каждом языке).
- **Диагностика**: неизвестный компонент или директива, свойство или событие, которого у компонента нет, `$Ref` без элемента с таким именем в шаблоне.
- **Подсветка**: компоненты, привязки, события, директивы, ссылки и `{{ }}` получают свои цвета, а их выражения подсвечиваются как JavaScript.

Проект, в котором есть только собранные файлы (`dist/elemenx.all.min.js`), получает всё это тоже: расширения несут исходники своей версии Elemenx и ElemenxUI.

## Шаблон и его компонент

Шаблон компонента — его `$TemplateURL`, `.html` с его именем рядом (`Board.html` рядом с `Board.js`) или `<template id="x">` страницы для определения с `$TemplateID: 'x'`. Имя в `$Template` (`'#x'`) отмечается как ошибка. Выражения шаблона видят то же, что даёт им Elemenx: поля и функции компонента, переменные циклов вокруг, `$T` и `$index`.

В WebStorm и IntelliJ IDEA выражения — это JavaScript самой IDE, а типы полей берутся из их значений: `Title: ''` — строка, `Rows: [{ID: 1}]` — массив `{ID: number}`, поэтому `Rows[0].` дополняет `ID`, а элемент `*for="row of Rows"` получает тип элементов. JSDoc над ключом задаёт ему тип, когда значение говорит слишком мало:
