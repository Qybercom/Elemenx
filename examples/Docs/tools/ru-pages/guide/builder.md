# Визуальный конструктор

`examples/Builder` — конструктор страниц: компоненты ElemenxUI берутся из палитры на холст, расставляются, получают свойства и раскладку, а результат — шаблон Elemenx, компонент или целое приложение. Он строит раскладку и свойства страницы, но не привязки и обработчики: их потом пишут в коде.

@block 1

## Проекты

Проект бывает одного из трёх видов, который выбирается при создании (Файл → Создать) и потом не меняется:

- **шаблон**: одна страница; результат — шаблон, который вставляется в компонент;
- **компонент**: компонент с публичными свойствами и слотами;
- **приложение**: страницы и компоненты, маршруты, охранники и настройки приложения (имя, заголовок, язык, тема и маршрутизатор).

Проекты хранятся в хранилище браузера (Файл → Открыть показывает их), их можно сохранить в файл и прочитать из файла.

## Экран

- **Лента**: Главная (отмена, повтор, копия, удаление, перемещение выбранного элемента), Проект (новая страница или компонент, настройки приложения), Вставка (все компоненты ElemenxUI и классы его раскладок по группам, с поиском) и Вид (ширина холста, контуры, отступы и линейки).
- **Холст** посередине: нажатый образец встаёт в выбранный элемент или после него; перетащенный — туда, куда его бросили. «Запустить» показывает страницу в работе, а инспектор показывает её элементы на ходу.
- **Структура** страницы слева — дерево, чтобы выбирать и перемещать элементы.
- **Раскладка и свойства** выбранного элемента справа; когда ничего не выбрано — сам документ (имя и маршрут страницы, свойства и слоты компонента). Правила CSS элемента могут зависеть от его состояния (hover, focus), ширины экрана и темы.
- **Шаблон** внизу, всегда в соответствии с холстом.

Клавиши: Mod+Z, Mod+Shift+Z (или Mod+Y), Mod+D (копия), Delete, Escape (снять выбор) и Alt для подсказок клавиш ленты.

## Результат

Файл → Экспорт даёт шаблон страницы, её правила впереди в `<style>`; Импорт читает шаблон обратно. Файл → Приложение скачивает страницу или приложение одним HTML-файлом, который работает сам по себе (фреймворк и ElemenxUI внутри), или проектом в zip (`index.html`, `app.js`, `elemenx.config.js` и компоненты в `application/`), готовым к `elemenx dev` и `elemenx build`; иконка, заставка и настройки PWA идут вместе с ним.

## Палитра

Палитра — не список, который ведут вручную: это `$Meta`, которые объявляют компоненты библиотеки (группа, иконка, описание, свойства с вариантами, события и образец, который вставляет палитра), а `elemenx meta` (`npm run meta` в репозитории) собирает их в `data/meta.json`. Тип свойства берётся из его значения по умолчанию. Компонент вашей библиотеки с `$Meta` появляется в палитре конструктора, который использует эту библиотеку.
