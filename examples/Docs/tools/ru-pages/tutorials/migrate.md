# Для знающих Vue, React или Angular

Идеи те же: компоненты с состоянием, шаблоны, которые следуют за ним, сервисы, маршрутизатор. Эта страница ставит слова Elemenx рядом с теми, что вы знаете, а затем показывает один компонент, написанный четырьмя способами.

## Тот же компонент

Счётчик с шагом, показанная сумма и сброс, о котором узнаёт родитель.

Поля определения — это сразу и состояние, и свойства: родитель задаёт их атрибутами (`Step="5"`) или привязками (`[step]="Size"`), а изменение поля перерисовывает то, что его читает. Нет ни `setState`, ни `ref()`, ни сигнала, который надо вызвать: `this.Count += 1` — это и есть изменение.

## Слова

| Vue | React | Angular | Elemenx |
| --- | --- | --- | --- |
| `data()`, `props` | `useState`, props | поля, `@Input()` | поля определения |
| `{{ value }}` | `{value}` | `{{ value }}` | `{{Value}}` |
| `:title="x"` | `title={x}` | `[title]="x"` | `[title]="X"` |
| `@click="go"` | `onClick={go}` | `(click)="go()"` | `(click)="Go"` |
| `v-model="name"` | `value` и `onChange` | `[(ngModel)]="name"` | `[(value)]="Name"` у нативного поля; `[value]` и `(change)` у компонента |
| `v-if` / `v-for` | `&&` / `.map()` | `*ngIf` / `*ngFor` | `*if` / `*for` (с `*key`) |
| `ref="box"` | `useRef` | `#box`, `@ViewChild` | `#Box` и `this.$Ref('Box')` |
| `$emit('reset')` | колбэк в props | `@Output()` | `this.$Emit('reset', data)` |
| `computed` | `useMemo` | геттер, `computed()` | функция, которую шаблон вызывает с тем, что читает: `{{Total(Items)}}` |
| `mounted` | `useEffect(..., [])` | `ngOnInit`, `ngAfterViewInit` | `$OnCreate` (до первой отрисовки), `$OnReady` (отрисован) |
| `unmounted` | очистка `useEffect` | `ngOnDestroy` | `$OnDestroy` |
| `provide` / `inject`, Pinia | контекст, стор | сервисы, DI | `Elemenx.Service` и `this.$Service('Name')`: один на приложение |
| Vue Router | React Router | Router | `$Router` приложения, `*outlet`, охранники |
| `<slot>` | `children` | `<ng-content>` | `<slot>` и `slot="name"` |
| `<style scoped>` | CSS-модули | стили компонента | `$StyleURL`, `$Style` или shadow root |

## Что иначе

- **Сборка не нужна.** Страница с одним `<script>` запускает Elemenx; CLI добавляет сервер разработки, генераторы и сборку, когда проект растёт. Код — ES5, который любой браузер выполняет как есть.
- **Функция шаблона — это метод.** `Total: function (items) {...}` в определении и `{{Total(Items)}}` в шаблоне: шаблон передаёт то, что читает, поэтому следует за ним. Обработчики событий — тоже методы (или функции, заданные в `$OnCreate`).
- **В API нет Promise.** Сервис или запрос отвечает колбэком `(error, result)` или событиями; охранник ждёт через `this.$Wait(function (done) {...})`.
- **Библиотека — часть фреймворка.** ElemenxUI (`$Use: ['ElemenxUI']`) содержит компоненты приложения — от кнопки до календаря, редактора кода и игрового мира — с темами, языками и управлением с клавиатуры и геймпада.
- **Один файл фреймворка.** `elemenx.js` содержит маршрутизатор, сеть (XHR, WebSocket, SSE, WebRTC...), хранилище, обмен сообщениями между вкладками и воркерами и service worker для PWA; сборка оставляет за бортом то, чем приложение не пользуется.
