# Своя библиотека

Acme — небольшая библиотека компонентов, которую компания делит между своими приложениями: карточка для важного числа, цена, текст для копирования. Со своим сервисом, фразами на двух языках, дизайн-токенами на основе токенов ElemenxUI и витриной, которая пишет свой справочник из того, что объявляют компоненты. Готовый проект — `examples/Tutorials/Kit`.

Чему вы научитесь: устройство библиотеки, её объявление и использование, компоненты, использующие сервис своей библиотеки, фразы и токены библиотеки, `$Meta` и `Elemenx.Meta` и что сборка берёт из библиотеки.

## 1. Устройство

@block 1

Библиотека устроена как приложение: файлы `index.js` перечисляют, что в ней есть, по порядку; у папки, названной в списке, есть свой `index.js`. Каждый компонент — папка со своими `.js`, `.html` и `.css`.

## 2. Объявление

@block 2

`$Use` называет библиотеки приложения. Тег, которого оно не знает (`<StatCard>`), ищется в них; их сервисы загружаются до старта корня, а CSS, перечисленный в их `index.js`, подключается один раз. Чтобы делить библиотеку между проектами, опубликуйте папку как пакет и укажите её путь в `$Root`.

Компонент библиотеки пишется как любой другой. Давайте его классам имя библиотеки (`acme-price`, `acme-stat`): стили библиотеки встречаются со стилями каждого приложения, которое её использует, и короткое имя вроде `.price` столкнулось бы с ними.

## 4. Фразы

Тексты компонентов — ключи библиотеки, а не слова в шаблонах:

@block 4

`locales/en.json` и `ru.json` хранят их под именем библиотеки (`acme.copy.action`), поэтому они не пересекаются с ключами приложения. Приложение может изменить фразу или добавить язык: `Elemenx.Locale.Add('de', {acme: {copy: {action: 'Kopieren'}}})`.

## 5. Токены

@block 5

Компоненты используют только `--acme-*`. Построенные на токенах ElemenxUI, они даром следуют его светлой и тёмной схемам и темам; продукт меняет свой бренд одной строкой (`:root { --acme-brand: #7c3aed; }`), и ни один цвет не пишется дважды.

## 6. Что объявляет компонент

@block 6

`$Meta` сообщает инструментам, что такое компонент: его группу и иконку в палитре, публичные свойства (тип или варианты списка), события, пример для показа. Состоянием он никогда не бывает. `Elemenx.Meta(name)` возвращает его в нормализованном виде, со значением по умолчанию каждого свойства, прочитанным из определения:

@block 7

Витрина проекта строит из него справочник: таблицу свойств каждого компонента и его события, написанные один раз, рядом с кодом, который они описывают. UI Builder Elemenx читает тот же `$Meta`, чтобы поместить компоненты библиотеки в свою палитру и инспектор.

## 7. Сборка

Сборка берёт из библиотеки только компоненты, которые приложение отрисовывает, — по их тегам в его шаблонах, а затем в их шаблонах; остальное остаётся за бортом. `$Meta` тоже вырезается, если только приложение его не читает (`Elemenx.Meta` в его коде или Designer), как витрина: тогда он остаётся.
