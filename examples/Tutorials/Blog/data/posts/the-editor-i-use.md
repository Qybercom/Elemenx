# The editor I use

The extension of Elemenx for my editor knows the components of the project:

| It does | Where |
| --- | --- |
| Completion | tags, props, events, directives |
| Go to definition | Ctrl+click on a tag or a prop |
| Diagnostics | an unknown prop is marked |

There are extensions for VS Code, the IDEs of JetBrains and Visual Studio.
